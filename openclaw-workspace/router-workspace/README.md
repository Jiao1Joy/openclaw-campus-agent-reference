# OpenClaw Campus Router Workspace

This repository stores the static OpenClaw Agent workspace used to route campus assistant requests into authorized capabilities.

It contains the Agent identity, behavior, tool guidance, heartbeat policy, and workspace instructions. Runtime state, sessions, credentials, tokens, logs, and local environment files are intentionally excluded from version control.

Restore this repository as:

```text
<OPENCLAW_HOME>/workspace-campus-router
```

The web application and server-side OpenClaw integration are located at the root of this public reference repository. Campus Skills, local knowledge, and Demo data are located in `openclaw-workspace/`.
