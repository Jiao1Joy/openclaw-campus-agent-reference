# 校园深度检索

## 数据边界

- 唯一事实来源是本工作区 `knowledge/` 下的本地校园知识条目。
- 不联网，不调用网页搜索，不读取其他工作区，不把模型记忆当作校园事实。
- OpenClaw 只负责拆解问题和规划查询；检索、可信过滤、引用和最终事实输出由校园 API 控制。

## 有界搜索

- 最多 3 个检索方向。
- 每个方向可以提供 1 个备用查询。
- 总检索次数最多 5 次；主查询已有可信证据时不执行备用查询。
- 只采用 `answerable=true` 且达到置信门槛的本地条目。
- 同一知识编号只引用一次。

## 输出原则

- 最终答案只展示采用条目的原始 `content`、来源、部门、更新时间和知识编号。
- 本地知识未覆盖的方向必须列入“暂无法确认”，不得推测。
- 所有内容标明为 Demo 数据，不代表真实学校规定。
- 全流程只读，不提供任何写操作或确认按钮。
