# 校园助手端到端演示

在 PowerShell 中从 `workspace-campus` 目录运行：

```powershell
.\demo\campus-e2e\run-demo.ps1
```

脚本会在系统临时目录创建隔离运行副本，演示结束后自动清理，并把本次摘要写入 `artifacts/actual-run.md` 和 `artifacts/actual-run.json`。如需保留完整的临时业务状态、事务日志和审计证据，可运行：

```powershell
.\demo\campus-e2e\run-demo.ps1 -KeepRuntime
```

## 简洁演示讲稿

1. “学生问：‘8 月 12 日上午请假会错过哪些课？’系统先用现有 Demo 课表做只读交集查询，命中《计算机网络》，随后生成完整请假摘要。此时状态是待确认，业务记录仍然不存在。”
2. “学生明确确认后，系统才提交请假。我们立即用相同幂等键重放一次：返回同一个申请编号，没有重复创建。接着校验 HMAC-SHA256 审计哈希链，结果无断链、无签名问题。”
3. “进入选课。规则引擎先要求学生在多个体育课教师中自主选择，再生成无冲突、满足必修与选修学分要求的待确认方案；学生确认后才提交，并在提交前重新校验名额、先修课、时间冲突和学分上限。”
4. “接下来只在临时副本中模拟一次跨文件半提交：名额已加一，但提交状态尚未落盘，同时保留事务日志。恢复命令识别到非终态事务，自动把名额补偿回原值并清除日志。”
5. “最后由运营角色在 30 分钟窗口内执行补偿回滚，再用同一幂等键重放。选课状态变为 rolled-back，临时课程名额完整恢复到基线，选课审计链也通过校验。”
6. “整个演示的所有写入都在临时目录；结束时再次计算 `data` 目录所有源文件的 SHA-256，与运行前完全一致，因此现有 demo 数据没有改动。”

## 演示边界

- 故障注入只修改临时课程副本，不触碰源 `data/course-data.json`。
- 审计使用固定的演示密钥，仅用于展示 HMAC 校验流程，不可用于生产环境。
- 输出不会记录完整幂等键、计划令牌或审计密钥。
