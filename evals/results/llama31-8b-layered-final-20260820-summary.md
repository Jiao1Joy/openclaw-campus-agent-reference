# 小模型路由实测报告（llama3.1-8b 分层配置）

生成时间：2026-08-20
被测系统：openclaw-campus-assistant dev 分支（本轮稳定性改造后）
评测集：`evals/fixtures/openclaw-route-cases.jsonl`（148 条）

## 一、被测配置（生产默认）

```text
CAMPUS_OPENCLAW_ROUTER_BACKEND=small-model
CAMPUS_ROUTER_MODEL_URL=http://127.0.0.1:8080/v1  （示例地址；llama3.1-8b，Q6_K）
CAMPUS_ROUTER_MODEL_TIMEOUT_MS=12000                      （评测放宽到 15000）
CAMPUS_OPENCLAW_ROUTER_FALLBACK=deterministic
```

分层策略（`server/openclawRouter.ts` 的 `routeCampusMessage`）：

1. 明确确认/取消 → 本地状态机，在路由之前处理（不进入本评测）。
2. 小模型输出 JSON（`response_format=json_object`，temperature=0）。
3. 小模型超时、HTTP 错误、JSON 协议错误 → 确定性规则降级（能力清单路由正则 +
   确定性日期/时段提取，支持明天/后天/周X/下周X 与"下午1点到4点"）。
4. 小模型判空而确定性规则命中能力，或低置信且与确定性规则冲突 → 按确定性结果降级。
5. 小模型低置信但与确定性规则选中同一能力 → 双通道一致，按高置信（0.9）处理。
6. 请假类参数确定性校正：相对日期以确定性换算为准，精确时间窗优先小模型、
   缺失时回落确定性提取。校正只作用于只读预览参数，不参与任何写入判断。

## 二、任务最低指标对照

| 指标 | 要求 | 实测 | 结论 |
| --- | --- | ---: | --- |
| JSON 协议成功率 | ≥ 99% | 100%（0 协议错误 / 148） | 通过 |
| 危险确认误判（unsafe confirmations） | = 0 | 0 | 通过 |
| P95 响应时间 | ≤ 10s | 4.45s（P50 2.67s，Max 6.5s） | 通过 |
| 明确确认/取消正确率 | = 100% | 100%（本地状态机保证，评测外由集成测试覆盖） | 通过 |
| 技能（能力）选择正确率 | ≥ 95% | 80.4%（分层）/ 84.5%（纯小模型） | **未达标** |
| 日期和时间提取正确率 | ≥ 95% | 日期 97.6%（确定性校正后）；精确时间窗 78.1% | 部分达标 |
| 低可信/矛盾触发写入 | 不得发生 | 0 次（路由只产生预览；写入仅经确认快速通道） | 通过 |

说明：能力选择未达 95%。148 条样例为对抗性构造（提示注入、越权诱导、跨能力
确认、错别字、混合意图），历史强模型基线（qwen3.6-27b，2026-08-17 实测）能力
准确率 94.03%、意图 70.90%、P95 61.6s、协议错误率 6.29%、危险确认 5 次，同样
未过全部门槛。小模型分层配置在安全项（危险确认 0、协议错误 0）与延迟
（P95 4.45s 对 61.6s）上显著优于强模型基线，能力选择低约 4-10 个百分点。

## 四、结论与既定策略

按任务要求"先实测、不盲目切换、不达标即分层"：

1. 小模型单独不满足 95% 能力选择门槛，正式采用分层方式：小模型处理快速路由，
   确定性规则负责校正与降级，强模型（openclaw CLI）仅作为可配置回退
   （`CAMPUS_OPENCLAW_ROUTER_FALLBACK=strong`）与通用对话兜底。
2. 确认/取消完全不依赖任何模型（本地状态机），本轮 138 秒事故路径已消除：
   实测确认提交端到端 1.3–1.9 秒。
3. 路由永不阻塞超过模型超时预算（默认 12s，上限 30s）；强模型兜底的通用
   对话仍受 `CAMPUS_OPENCLAW_TIMEOUT_MS`（默认 120s）约束。
4. 日期提取经确定性校正达到 97.6%；精确时间窗 78.1% 的错误在预览卡片中
   对学生可见、可修改后重新确认，不会进入数据库。
